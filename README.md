# ccna-labs

Packet Tracer labs I'm doing while following Jeremy's IT Lab CCNA course on YouTube.

What each lab covers:

* day1 - basic network devices, building a small topology
* day2 - cable types, connecting devices with the right interfaces
* day3 - TCP/IP model, watching encapsulation in simulation mode
* day4 - IOS CLI basics, config modes, saving the config
* day6 - how switches learn MAC addresses, ARP and ping
* day8 - IPv4 addressing, assigning IPs to router interfaces
* day9 - switch port settings, speed/duplex and autonegotiation
* day10 - ipv4 header fields (theory, no lab)
* day11 - routing fundamentals, routing table, route selection (theory, lab in day12)
* day11(Part-1) - Static Routing - static routes on R1, R2 and R3 (PC1 to PC2 ping)
* day11(Part-2) - Static Routing troubleshooting lab - found and fixed misconfigured routes and interface IP addresses
* day12 - Life of a Packet lab - traced a ping hop by hop in simulation mode (ARP, MAC rewrite at each router)
* day13 - subnetting basics. learned how to split a /24 network into subnets, calculating host bits (2^n - 2), prefix lengths and block sizes
* day14 - subnetting practice. solved class C questions (find the subnet of a given host, list subnets with their ranges) and started subnetting class B networks
* day15 - Subnetting Part 3 (VLSM) - allocated different-sized subnets from a single network based on host requirements
* day16(Part-1) - VLANs Part 1 lab - assigned switch ports to VLANs as access ports and configured router interfaces as gateways for each VLAN subnet
* day17 - vlans part 2. learned how vlans split a switch into separate broadcast domains, assigning access ports to vlans and mapping one subnet per vlan
* day18 - VLANs Part 3 - native VLAN on a router (ROAS) and Layer 3 switching with SVIs

Will keep adding as I go through the course.
